# Northwind Gadgets — Refund Policy Update

Effective November 2026

## How long do I have to request a refund?
Policy update, November 2026: the refund window is now **3 days** from the delivery date. This replaces the previous 30-day window, which no longer applies.

## Returning an item
Policy update, November 2026: items can only be returned within 3 days of delivery. This replaces the previous 30-day window, which no longer applies.
